# Route the 24 principles by the actual decision

Read only triggered originals below. Paths point to unchanged pinned source documents, whose invocation/tool/authority assumptions are adapted by SKILL.md and ~/.codex/harness/references/integration.md. Multiple stages may select the same principle; read once, apply when relevant. Do not introduce a new process merely to exercise an unused principle.

| When | Principle / original | What decision it changes |
|---|---|---|
| Planning a nontrivial change or adding layers | [Laziness Protocol](upstream/pstack/principle-laziness-protocol/source.md) | Choose the smallest sufficient change and one owner per repeated decision, considering correctness and maintenance rather than line count alone. |
| Core data shapes, infrastructure or shared state | [Foundational Thinking](upstream/pstack/principle-foundational-thinking/source.md) | Set the core model and required foundation before dependent business logic; keep test-first. |
| Integrating a new requirement in an existing design | [Redesign from First Principles](upstream/pstack/principle-redesign-from-first-principles/source.md) | Sketch how it would fit from day one; obtain approval before a material redesign. |
| Two fixes sharing one premise fail the same check | [Attack the Premise](upstream/pstack/principle-attack-the-premise/source.md) | State and test that premise before trying another symptom patch. |
| Adding features atop known dead weight | [Subtract Before You Add](upstream/pstack/principle-subtract-before-you-add/source.md) | Remove proven obsolete complexity within scope, with before/after checks; preserve necessary compatibility and negative tests. |
| Review or code difficult to follow | [Minimize Reader Load](upstream/pstack/principle-minimize-reader-load/source.md) | Reduce hidden state and needless navigation while keeping genuine boundary responsibilities. |
| Approved phased migration/rewrite | [Outcome-Oriented Execution](upstream/pstack/principle-outcome-oriented-execution/source.md) | Converge toward the accepted target rather than build temporary compatibility debt. Do not waive mandatory TDD, stage checks or the approved migration boundary. |
| User experience versus implementation convenience | [Experience First](upstream/pstack/principle-experience-first/source.md) | Preserve the complete accepted user outcome; explain scope/cost choices for the user. “Ship” does not authorize publishing. |
| Important design with no usable precedent | [Exhaust the Design Space](upstream/pstack/principle-exhaust-the-design-space/source.md) | Compare two or three small alternatives when experience/structure cannot be settled from evidence; prototype only within authorized scope. |
| Repeated or nontrivial operation/proof | [Build the Lever](upstream/pstack/principle-build-the-lever/source.md) | Reuse a deterministic tool first; create a scoped rerunnable helper when justified. Do not turn every small edit into a tool/Skill project. |
| Repeated state/business assumptions or branching | [Model the Domain](upstream/pstack/principle-model-the-domain/source.md) | Put the business invariant in an appropriate canonical model instead of scattered conditionals; reuse the existing glossary authority. |
| Input validation, errors or framework adapters | [Boundary Discipline](upstream/pstack/principle-boundary-discipline/source.md) | Validate real external boundaries and separate pure calculation from effects. Internal trust requires proven boundaries, including stored/JSON/IPC data. |
| Static type design or unsafe casts | [Type System Discipline](upstream/pstack/principle-type-system-discipline/source.md) | Encode meaningful distinctions/legal states; do not force a new language or pretend runtime boundaries are typechecked. |
| Retries, writes, lifecycle or restart | [Make Operations Idempotent](upstream/pstack/principle-make-operations-idempotent/source.md) | Make repeated execution converge to the same result; test partial failures and surviving effects. |
| Approved internal API replacement | [Migrate Callers Then Delete Legacy APIs](upstream/pstack/principle-migrate-callers-then-delete-legacy-apis/source.md) | Migrate known callers and remove the obsolete API only after proving compatibility assumptions and approved scope. |
| Concurrent writers sharing a file/branch/key/state | [Separate Before Serializing Shared State](upstream/pstack/principle-separate-before-serializing-shared-state/source.md) | Consider independent owned state before locks/queues; preserve needed shared invariants and migration approval. |
| Before claiming a runnable artifact complete | [Prove It Works](upstream/pstack/principle-prove-it-works/source.md) | Exercise the real user surface and verify content/side effects, not a proxy or agent self-report. |
| Debugging or repeated symptom guards | [Fix Root Causes](upstream/pstack/principle-fix-root-causes/source.md) | Reproduce and trace the earliest wrong state; repair known instances inside scope and report out-of-scope ones. |
| Multi-step coding or migrations | [Sequence Verifiable Units](upstream/pstack/principle-sequence-verifiable-units/source.md) | Finish a meaningful check per small unit before advancing. Identify the real baseline and WIP; do not automatically rebase onto trunk. |
| Writing/changing/evaluating tests | [Test Behavior, Not Implementation](upstream/pstack/principle-test-behavior-not-implementation/source.md) | Check externally observable contracts and independent expected outcomes; keep tests resilient to harmless restructuring. |
| Reporting benchmarks or evaluation numbers | [Explain the Number](upstream/pstack/principle-explain-the-number/source.md) | State what was measured, limiting factors and alternative explanations; unknown cost/tokens stay unknown. |
| Large reads/output or context pressure | [Guard the Context Window](upstream/pstack/principle-guard-the-context-window/source.md) | Bound reads and keep bulk data in artifacts. Any delegation remains subject to available permission, scoped tasks and review budgets. |
| Already authorized reversible execution | [Never Block on the Human](upstream/pstack/principle-never-block-on-the-human/source.md) | Complete concrete reviewable work without repeating settled approval questions. Pause dependent work for a genuinely new consequential decision. |
| Repeated correction or workflow failure | [Encode Lessons in Structure](upstream/pstack/principle-encode-lessons-in-structure/source.md) | Propose a narrowly owned test/check/structure to prevent recurrence. No automatic memory/global-rule/Skill adoption. |

For each applied principle retain: the real trigger, decision before/after, reason/evidence, and any unresolved tradeoff. Reuse the project's existing record. Never count “24 principles loaded” as a quality metric or a substitute for actual verification.
